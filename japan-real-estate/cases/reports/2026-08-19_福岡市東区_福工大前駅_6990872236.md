## Step 3：投報率計算

### 表面投報率

```
表面投報率 = 月租金 × 12 ÷ 取得価格
           = 11万 × 12 ÷ 3,600万
           = 132万 ÷ 3,600万
           = 3.67%
```

### 實質投報率計算

**取得費用（含取得成本）**
```
不動產取得税：評価額2,160万 × 3% = 64.8万
登録免許税：評価額2,160万 × 2% = 43.2万
仲介手数料（談判目標1%）：3,600万 × 1% = 36万
  （如不能談判，按上限3.3%計算：119.9万）
印紙税：7.5万
登記費用（代書）：15万
火災保険：20万
───────────────────────────
取得費用合計（談判目標）：約 186万（≈5.2%）
取得費用合計（上限）：約 270万（≈7.5%）
實際総投入（談判目標）：3,600万 + 186万 = 3,786万
```

**固定資産評価額估算**
```
評価額 = 土地評価額 + 建物評価額
土地評価額 ≈ 3,600万 × 60% = 2,160万（土地比率高）
建物評価額 ≈ 殆零（軽量鉄骨37年，折舊已完成）

固定資産評価額 ≈ 2,160万
```

**年間持有コスト**
```
固定資産税：2,160万 × 1.4% = 30.2万/年
都市計画税：2,160万 × 0.3% = 6.5万/年
───────────────────────────
年間持有コスト合計：36.7万/年
（無管理費/修繕金，自有建物）
```

**實質投報率**

```
実質投報率 = （年間租金 - 年間持有コスト）÷ 取得価格
           = （132万 - 36.7万）÷ 3,600万
           = 95.3万 ÷ 3,600万
           = 2.65%（中性估算12萬：3.47%）
```

### 雙軌道投資分析

```
【路線 A：純投資（轉售為前提）】
- 土地占比：約60%（主要價值在土地）
- 軽量鉄骨37年：建物殆零，折舊乾淨
- 土地長線保值性：福岡东区和中長期仍穩定
- 風險：建蔽率/容積率低（50%/80%）限制重建規模

【路線 B：出租（現金流為前提）】
- 実質投報率：2.65-3.31%（不含空室/管理/維修）
- 加上空室風險（郊區5LDK需求有限）：實質約2-3%
- 東京同期存款利率約2%，本案件略優或持平

【結論】
□ 偏重出租現金流 → ❌ 投報率過低，不建議
□ 偏重資產保值增值 → ⚠️ 土地價值存在，但需大議價
□ 兩者兼得 → ❌ 目前訂價不合理，必須議價
```

## 💡 總結建議

### ✅ 優點
- 土地面積282m²（85坪），在福岡郊区属中等规模，長線有土地保值性
- 南向き + 吹拔 + 屋上バルコニー，格局有吸引力
- 都市ガス + 下水道，設備齊全
- 無需擔心私道問題

### ⚠️ 缺點與風險
- **投報率過低**：表面3.67%，實質約2.65%，遠低於福岡平均5-6%
- **無停車位**：郊区5LDK無停車，削弱出租競爭力
- **建蔽率/容積率低**：50%/80%，重建規模受限
- **軽量鉄骨37年**：建物価値殆零，未來轉售談判力弱
- **外國人持有成本**：源泉徵收20.42%，實收再打折扣

### ❌ 建議

**❌ 不建議以3,600萬購入（投報率過低）**

**⚠️ 若真的要買，談判目標：2,500-2,800萬**
- 2,640萬 → 表面投報率5%（基本合理門檻）
- 2,500萬 → 表面投報率5.28%，較有投資價值
- 低於2,500萬 → 可考慮（但賣方不一定接受）
