# 🚀 外國人在日本買房流程

---

## 一、回答你最關心的問題

**外國人能買嗎？**
可以 ✅ 不需要日本國籍、不需要永住權、不需要工作簽證。

**但需要什麼？**
- 🏦 日本銀行帳戶（收款、匯款用）
- 📝 代書（土地上家屋所有人，外國人不能自己辦過戶）
- 🛂 護照 + 翻譯公證
- 💰 資金（多數台灣人用現金購入，銀行對外國人房貸很保守）

---

## 二、買房步驟 Step by Step

```
Step 1：準備資金 + 開日本銀行帳戶
        ↓
Step 2：找不動產經紀 + 看屋
        ↓
Step 3：出價 + 簽約（支付手付金 10%）
        ↓
Step 4：過戶登記（代書代辦）
        ↓
Step 5：取得權利書 ✅
        ↓
Step 6：申請民宿許可
        ↓
Step 7：上架 Airbnb
```

---

## 三、日本銀行帳戶怎麼開？

### 人在台灣可以先做的

| 銀行 | 做法 |
|------|------|
| **台灣銀行東京分行** | 在台北就能先開戶，最推薦！ |
| 兆豐銀行東京分行 | 同上 |
| 第一銀行東京分行 | 同上 |

### 到日本後可以開的

| 銀行 | 特色 |
|------|------|
| **住信SBIネット銀行** | 網路銀行，審查較寬鬆 |
| **新生銀行 (Shinsei)** | 對外國人友善 |
| 三井住友銀行 (SMBC) | 大型銀行，審查嚴格 |

> 💡 建議先用「台灣銀行東京分行」在出發前就把帳戶開好，省時間。

## 四、資金匯款流程

```
台灣帳戶（外幣帳戶）
    ↓ SWIFT 電匯（2-5個工作天）
日本帳戶
    ↓
支付尾款給賣方 + 手付金
```

**費用參考：**
- 電匯手續費：NT$2,000～5,000（視銀行）
- 日本端受領費：¥2,500～4,000

---

## 五、代書（土地上家屋所有人）做什麼？

外國人無法自己向法務局辦理不動產過戶，**一定要找代書**。

### 代書能幫你做：
- ✅ 過戶登記（所有權移轉）
- ✅ 製作買賣契約
- ✅ 申請民宿許可
- ✅ 處理固定資產稅申報
- ✅ 對應稅務署

### 怎麼找代書？
- 不動產經紀通常有配合的代書（最簡單）
- 或搜尋「名古屋 土地家屋所有人」，找評價好的
- 費用約 ¥10～30萬日幣（事先要求報價）

```

```

## 七、買房成本（一次性費用）

| 項目 | 費用 |
|------|------|
| 不動產取得稅 | 評価額 × 3%（住宅）|
| 登錄許可稅 | 土地：評価額 × 1.5%，建物：× 0.3% |
| 契約印花稅 | ¥10,000～50,000 |
| **代書費** | **約 ¥10～30萬（重要）** |
| 火災保險 | 約 ¥2～5萬/年 |
| 過戶登記代辦 | 約 ¥10～20萬 |

**預估總成本：約為房價的 7～10%**

```
例：房價 ¥1,500萬
一次性成本約：¥105萬～¥150萬
```

## 八、一戶建（透天）vs 公寓（マンション）

| | 一戶建（透天）| 公寓 |
|---|---|---|
| **適合 Airbnb** | ✅ 隱私性高、空間大 | ⚠️ 管委會可能禁止 |
| 價格 | ¥800萬～3,000萬 | ¥1,000萬～5,000萬 |
| 維護成本 | 較高（外牆、屋頂自己負責）| 有管理費，但省事 |
| 管理複雜度 | 較高 | 較低 |
| **推薦度** | ⭐⭐⭐⭐⭐ 做民宿首選 | 僅長租 |

## 九、流程時間表

| 階段 | 時間 |
|------|------|
| 找房 + 看房 | 1～3個月 |
| 簽約到手付金 | 當天或數天內 |
| 過戶登記 | 1～2個月 |
| 民宿許可申請 | 2～4週 |
| Airbnb 上架 | 許可下來後即可 |

**從決定到開始營運：約 2～4 個月**

---

## ⚠️ 常見陷阱

1. **不看用途地域就買** → 買到住宅區但當地條例不允許民宿
2. **無視管理規約** → 公寓大樓禁止民宿，被管委會告
3. **代書費用沒談清楚** → 事先要求報價單
4. **低估持有成本** → 固定資產稅、管理費、代管費都要算
5. **匯率風險** → 日幣波動大，租金換回台幣可能變少

---

## 十、外國人房貸說明

多數台灣投資者傾向用**現金購入**，因為日本銀行對外國人房貸很保守。

如果你真的想申請房貸，需要：
- 日本在留資格（工作簽證等）
- 日本境內收入證明
- 通常頭期款需 30～40%

**結論：準備好現金是最簡單的方式。**
