# AI 設計 10 大 Skill 推薦：完整指南

> 讓 AI Coding Agent 不僅「把功能做出來」，還能提升畫面的完成度與設計品質。
> 分類涵蓋：UI 設計、審美校準、設計系統、網頁動效、風格提取、Landing Page、敘事式 UI 等。
> 適用對象：Claude Code、Codex、OpenCode 等 AI 開發工具使用者。

---

## 🎯 核心價值：為什麼需要這些 Skill？

隨著 AI Coding Agent 越來越普及，很多人已經發現一個問題：

> AI 做出來的網站，常有一股熟悉的「AI 模板味」。

這不只是美觀問題，更關乎產品的完成度與專業感。這 10 個 Skill 的最大價值，就是把原本只擅長「完成功能」的 AI，進一步加入明確的設計規則與審美脈絡，讓產出的網站不只是功能完整，畫面也更有完成度。

## 📌 01. Hallmark

| 屬性 | 內容 |
|------||------|------|------|
| **名稱** | Hallmark |
| **分類** | 審美校準 |
| **核心功能** | 反 AI 味的網頁審美校準，協助改善 AI 常見的制式化設計風格，讓產出的網頁看起來更自然、更具有設計感。 |
| **解決的痛點** | AI 產生的網頁常有「排版太整齊、配色太安全、間距太死板」的問題，整體看起來有「機器自動產生」的味道。Hallmark 在這個層面上做校準。 |
| **適用場景** | - 一般網站首頁、About 頁、部落格<br>- 任何你希望介面「不那麼像機器做的」的情境<br>- 與其他 Skill 搭配使用（先產生基礎版面，再用 Hallmark 做審美校準） |
| **使用時機** | 當你已有初步版面，但覺得整體氛圍不夠自然、設計感不足時 |
| **注意事項** | Hallmark 偏向品質面向的微調，不會從零建立設計系統。建議在有初步版面之後再使用。 |
| **倉庫/連結** | https://github.com/Nutlope/hallmark |

> **給其他 AI 的使用指引**：當使用者要求設計網頁，且你希望產出的介面不具備制式化、模板化的風格時，可調用 Hallmark Skill 進行審美校準。重點調整間距、對齊方式、配色層次、字體層次感與整體氛圍。

## 📌 02. Open Design

| 屬性 | 內容 |
|------|------|
| **名稱** | Open Design |
| **分類** | 設計系統 |
| **核心功能** | AI 設計工作台，著重於原型與設計系統之間的協同，適合需要建立一致 UI 規範與設計流程的專案。 |
| **解決的痛點** | 當你同時有多個頁面、需要保持一致性（配色、間距、圓角、陰影、字型層次），但 AI 每次都自行其是時，Open Design 幫你建立中間的規範。 |
| **適用場景** | - SaaS 產品、多頁面網站、仪表板<br>- 團隊協作，需要大家遵循同一套設計規範<br>- 希望未來新頁面能快速套用既有規範 |
| **使用時機** | 當你計劃建立一個包含多個頁面、需要長期維護一致性的產品時 |
| **注意事項** | Open Design 重在建立規範。有了規範後，後續開發才能更一致。若只是做一個單一頁面，可能不需要完整的設計系統。 |
| **倉庫/連結** | https://github.com/OtherdaysStudio/design-system-consistency |

> **給其他 AI 的使用指引**：當使用者需要建立設計系統或確保多頁面一致性時，可調用 Open Design Skill。產出應包括：顏色系統、字型層次、間距標度、元件風格規範（按鈕、輸入框、卡片、導航等）。之後開發新頁面時，AI 應參考這份規範。

## 📌 04. Taste Skill

| 屬性 | 內容 |
|------|------|
| **名稱** | Taste Skill |
| **分類** | 視覺提升 |
| **核心功能** | 主要用來降低 AI 產生介面的「模板感」，提升畫面質感、視覺層次以及整體設計判斷。 |
| **解決的痛點** | AI 做的網頁常有一個共通的問題：看起來像是從某個通用模板改的，缺乏個性與特殊的設計判斷。Taste Skill 的作用，就是在這一層面上提升。 |
| **適用場景** | - 任何你覺得網頁「看似可以，但差一點質感」的情境<br>- 與其他 Skill 搭配：先產生基礎，再用 Taste Skill 提升質感<br>- 希望介面有更多「設計感」的個人網站、作品集、行銷頁面 |
| **使用時機** | 當介面雖然功能完整，但整體質感、設計感不足時 |
| **注意事項** | Taste Skill 與 Hallmark 類似，但 Hallmark 更偏向審美校準（整體氛圍、對齊、間距），Taste 更偏向降低模板感與提升質感（細節、判斷、質地）。兩者可以搭配使用。 |
| **倉庫/連結** | https://github.com/Leonxlnx/taste-skill |

> **給其他 AI 的使用指引**：當使用者對網頁的視覺質感不滿意，覺得有「模板感」時，可調用 Taste Skill。重點提升字體選擇與層次、配色調整、微互動或過渡效果、排版節奏、細節（圖片排列、hover 效果、連結風格等）。

## 📌 05. GSAP Skills

| 屬性 | 內容 |
|------|------|
| **名稱** | GSAP Skills |
| **分類** | 動效設計 |
| **核心功能** | 針對網頁動畫與互動效果，包含滾動觸發、時間軸編排等設計，適合希望加入更豐富網頁動效的專案。 |
| **解決的痛點** | 純靜態網頁在現代網站中有時顯得平淡；加入適當的動畫可以提升整體質感與使用者體驗。GSAP 是目前 Web 動畫領域中成熟、強大的工具。 |
| **適用場景** | - 需要滾動時觸發動畫的長頁面、作品集<br>- 標語、圖片、按鈕進場動畫<br>- 複雜的時間軸動畫（多個元素依序出現、交叉淡入、位移）<br>- 互動式動畫（點擊展開、滑動切換） |
| **使用時機** | 當你希望網站加入動畫效果，提升整體氛圍與使用者體驗時 |
| **注意事項** | 動畫不要過度：太多動畫反而讓介面顯得雜亂、無效率。性能考量：GSAP 動畫要注意在低效能裝置上的表現。若你不需要複雜動畫，可能僅需簡單 CSS 動畫就夠了。GSAP 適合需要時間軸控制、滾動交互、複雜序列的情境。 |
| **倉庫/連結** | https://github.com/greensock/GSAP（官方）| https://gsap.com/（官網）|

> **給其他 AI 的使用指引**：當使用者希望網站加入動畫效果，且需要時間軸控制、滾動交互、複雜序列時，可調用 GSAP Skills。產出應包含 GSAP 程式碼、ScrollTrigger 設定、timeline 設計。動畫應有目的（引導注意力、增強氛圍、提供反饋），而非單純為了炫技。

## 📌 06. PencilPlaybook

| 屬性 | 內容 |
|------|------|
| **名稱** | PencilPlaybook |
| **分類** | UI 規則 |
| **核心功能** | 提供設計心理學導向的 UI 規則與方法，讓 AI 在安排介面元素時，不只是考慮美觀，也能兼顧使用者體驗。 |
| **解決的痛點** | 有些介面看似美觀，但實際使用起來卻不直觀、不易操作。PencilPlaybook 的價值，在於從設計心理學、使用者行為角度，提供 UI 排版與元素安排的原則。 |
| **適用場景** | - 需要兼顧功能與使用者體驗的介面<br>- 按鈕放置、表單排版、信息架構、使用者流程設計<br>- 希望 AI 不只是「做出好看的東西」，也能考慮「如何讓使用者好操作」 |
| **使用時機** | 當設計任務涉及使用者操作流程、表單、按鈕布局、信息架構等，需要兼顧實用性時 |
| **注意事項** | PencilPlaybook 重在原理與規則，不直接產出具體的 code 或設計稿。它適合用來指導 AI 的設計判斷，讓產出的介面不只是好看，也好用。 |
| **倉庫/連結** | https://github.com/stevembarclay/pencilplaybook |

> **給其他 AI 的使用指引**：當設計任務涉及使用者操作流程、表單設計、按鈕布局、信息架構等，需要考慮使用者體驗時，可參考 PencilPlaybook 的規則。重點欄位排列順序是否符合使用者心智流程、錯誤訊息的呈現位置與語氣、提交按鈕的位置與促銷力道、是否有不必要的欄位造成負擔、視覺層次是否讓使用者一眼看到最重要行動。

## 📌 07. design-md-chrome

| 屬性 | 內容 |
|------|------|
| **名稱** | design-md-chrome |
| **分類** | 風格提取 |
| **核心功能** | 可以提取網站的視覺與設計風格，並生成 DESIGN.md 作為後續 AI 開發與設計時的參考。 |

| **適用場景** | - 你有參考對象（某個網站的風格你很喜歡）<br>- 希望新網站能有類似的設計風格（配色、字體、間距、氛圍）<br>- 將風格規格寫成設計文件，供後續 AI 任務持續參考 |
| **使用時機** | 當你希望新網站擁有特定的設計風格，並有具體的參考對象時 |

| **倉庫/連結** | https://github.com/bergside/design-md-chrome |

> **給其他 AI 的使用指引**：當使用者希望網站擁有特定設計風格，且有具體的參考網站時，可調用 design-md-chrome 提取風格。產出 DESIGN.md 應包含：配色系統、字體與字型層次、間距與排版風格、整體氛圍、元件風格。之後開發新網站時，AI 應參考這份文件，確保風格一致性。

## 🔄 10 大 Skill 的相互關係與搭配建議

這 10 個 Skill 並非各自獨立，而是有層次與互補關係。你可以根據需求分層搭配。

### 🔹 第一層：基礎設計品質（審美與視覺）

| Skill | 定位 |
|-------| ------|
| **Hallmark** | 審美校準，降低制式化 |
| **Taste Skill** | 提升質感，降低下模板感 |
| **PencilPlaybook** | 設計心理學規則，兼顧好用性 |

**搭配方式**：
- 先用 Hallmark 或 Taste 校準整體審美
- 搭配 PencilPlaybook 確保操作層面合理

### 🔹 第二層：設計系統與規範

| Skill | 定位 |
|-------|------|
| **Open Design** | 設計系統與規範建立 |

**搭配方式**：
- 當你有多頁面或產品線，需要一致性時，建立設計系統
- 建立後，後續開發可參考這套規範

### 🔹 第三層：特定頁面／用途設計

| Skill | 定位 |
|-------|------|
| **UI/UX Pro Max Skill** | SaaS 與 Dashboard 介面 |
| **Claude Design Skill** | 綜合設計（Landing Page、海報、原型） |
| **Landing Page Generator** | 高轉換落地頁結構與內容 |
| **Cinematic UI** | 電影感、敘事視覺 |

**搭配方式**：
- 根據需求選擇：
  - 想做儀表板：UI/UX Pro Max
  - 想做落地頁：Landing Page Generator（優先）或 Claude Design Skill（綜合）
  - 想做電影感網站：Cinematic UI
  - 想做多種設計類型：Claude Design Skill（一體化）

### 🔹 第四層：風格與動效

## 💡 實戰建議與最佳做法

### 1. 技能不是萬靈丹

每個 Skill 都有特定的適用範圍。不適合的情境硬用，可能效果有限，甚至產生多餘的複雜度。

- 在功能導向的 Dashboard 上硬加電影感動畫（Cinematic UI + GSAP），可能分散使用者注意力。
- 在單一 Landing Page 上硬建立完整設計系統（Open Design），可能過猶不及。

**建議**：先想清楚這個頁面的主要目標（轉換、資訊傳達、氛圍、操作效率等），再選擇合適的 Skill。

### 2. Skill 之間的順序很重要

不同 Skill 的特性不同，先後順序會影響結果。

- **先建立規範（Open Design） → 再開發頁面**：適合多頁面、需要一致性的情境
- **先產生基礎版面 → 再用 Hallmark/Taste 校準**：適合單一頁面，希望事後提升質感
- **先提取風格（design-md-chrome） → 再用規範開發**：適合有參考對象的情境

**建議**：根據你的工作流程，決定 Skill 的使用順序。

### 3. 過度使用動畫可能損害體驗

GSAP Skills 很強大，但動畫太多、太複雜，可能：

- 讓介面顯得雜亂
- 降低操作效率（使用者要等動畫結束才能操作）
- 在效能較弱的裝置上表現不佳

**建議**：動畫要有目的（引導注意力、增強氛圍、提供反饋），而非單純為了「看起來很炫」。微量、高品質的動畫，往往比大量雜亂動畫更好。

### 4. 設計系統不是越詳細越好

Open Design 提供建立設計系統的輔助，但設計系統本身也需要維護與更新。如果你的專案很小（例如單一 Landing Page），可能不需要完整的設計系統。反之，如果你的產品有多個頁面、長期維護，設計系統的投資才更有價值。

**建議**：根據專案規模與長遠規劃，決定設計系統的詳細程度。

### 5. 與 AI 的溝通方式很關鍵

Skill 的效果，很大程度取決於你如何向 AI 說明需求。

```
差的指示：
  "幫我做一個網站"

好的指示：
  "幫我做一個 SaaS 產品的登陸頁，目標是讓訪客註冊試用。
   風格偏向專業、乾淨、現代。
   使用 Landing Page Generator 規劃結構，
   再搭配 Taste Skill 提升視覺質感。"
```

**建議**：向 AI 說明清楚的目標、受眾、風格偏好、希望使用的 Skill，有助於 AI 做出更符合 expectations 的結果。

| 08 | **Claude Design Skill** | 綜合設計 | Landing Page、海報、原型設計的一體化輔助 | 需要多種類型視覺設計的情境 |
| 09 | **Landing Page Generator** | 落地頁 | 專注高轉換落地頁結構與內容生成 | 產品介紹、服務宣傳、行銷活動頁面 |
| 10 | **Cinematic UI** | 敘事視覺 | 電影感、敘事化 UI 與互動布局 | 故事性強的網站、氛圍導向的設計任務 |

## 🎬 結語

這 10 個 Skill 的價值，在於幫助 AI 不僅僅是「把功能做出來」，而是進一步加入設計規則、審美脈絡、動效與氛圍。

對使用 AI Coding Agent 開發網站的人來說，最大的好處是：

- 當你常常覺得 AI 做出的網站有「AI 模板味」時，可以透過不同 Skill 的搭配，改善最終成品的視覺品質與一致性。
- 根據需求選擇合適的 Skill 組合，讓 AI 的設計輸出更貼近你的 expectations。

這份文件的目的，是讓其他 AI 在面對設計相關任務時，能理解這 10 個 Skill 的定位與用途，並根據需求選擇合適的組合。
