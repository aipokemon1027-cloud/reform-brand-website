## Step 3：投報率計算

### 表面投報率

```
表面投報率 = 月租金 × 12 ÷ 取得価格
           = 5万 × 12 ÷ 1,000万
           = 60万 ÷ 1,000万
           = 6.00%（保守估算5萬/月）
（6萬/月：72万 ÷ 1,000万 = 7.20%）
```

### 實質投報率計算

**固定資産評価額估算**
```
評価額 = 土地評価額 + 建物評価額
土地評価額 ≈ 1,000万 × 65% = 650万
建物評価額 ≈ 殆零（RCB構造50年 >> 耐用年数47年）

固定資産評価額 ≈ 650万
```

**年間持有コスト**
```
固定資産税：650万 × 1.4% = 9.1万/年
都市計画税：650万 × 0.3% = 1.95万/年
───────────────────────────
年間持有コスト合計：11.05万/年
```

**實質投報率**
```
実質投報率 = （年間租金 - 年間持有コスト）÷ 取得価格
           = （60万 - 11.05万）÷ 1,000万
           = 48.95万 ÷ 1,000万
           = 4.90%（保守估算5万/月）

（6萬/月：60.95万 ÷ 1,000万 = 6.10%）
```

### RCB構造的重要說明

```
【RCB（鉄筋コンクリートブロック造）】
- 法定耐久年数：47年（RC造同等）
- 本案：1976年築 → 2026年 → 50年
- 50年 > 47年 → 税法上：評価額 ≈ 0
- 但 Okinawa 特殊性：RCB在 Okinawa 较常见，结构上仍有一定的耐久性

【重要提醒】
- RCB 不是 RC（鋼筋混凝土），是「鋼筋混凝土砌塊結構」
- 耐久性比RC低，修繕費用可能較高
- 需要現場確認結構安全
```
