## 一、日本不動產的基本法令框架

### 不動產交易的相關法規

| 法規名稱 | 內容 |
|----------|------|
| **不動產登記法** | 所有權移轉、抵押權設定等登記手續 |
| **不動產取得稅法** | 取得不動產時繳納的稅金 |
| **固定資產稅法** | 持有不動產每年繳納的稅金 |
| **都市計劃法** | 土地用途地域的劃分 |
| **建築基準法** | 建築物的結構、設備、安全標準 |
| **消防法** | 消防設備設置標準 |
| **民泊新法（住宅民宿事業法）** | 民宿合法經營的框架 |

## 二、用途地域與土地分類

### 日本都市計劃法規定的用途地域

名古屋的土地分為不同的「用途地域」，決定了可以做什麼：

| 地域類型 | 民宿許可 | 說明 |
|----------|:--------:|------|
| 第一種低層住居地域 | ✅ 可 | 純住宅區，原則上可做民宿 |
| **第二種住居地域** | ✅ 可 | 可做民宿，是主要候選區域 |
| 準住居地域 | ✅ 可 | 住宅為主，可申請民宿 |
| **商業地域** | ✅ 可（視條例）| 原則更彈性，但要注意額外限制 |
| 準工業地域 | ⚠️ 可（視條例）| 輕工業混合，可能有彈性 |
| 工業地域 | ❌ 不可 | 原則上不准民宿 |
| 工業專用地域 | ❌ 不可 | 絕對不准 |

### 如何查詢用途地域？

**方法一：自己查**
```
1. 前往「都市計画圖」（都市計画マップ）
2. 輸入地址
3. 查看該土地的地域分類
```

**方法二：請代書幫忙查**
- 最簡單的方式
- 代書通常有資料庫可以快速確認

**方法三：去區公所查**
- 各區的都市計画課可以查詢
- 免費，但需要親自去

## 三、外國人在日本不動產的稅務義務

### 外國人需要知道的稅種

| 稅種 | 繳納頻率 | 說明 |
|------|----------|------|
| **不動產取得稅** | 一次性（購入時）| 評価額 × 3%（住宅）|
| **登錄許可稅** | 一次性（購入時）| 土地：評価額 × 1.5%，建物：× 0.3% |
| **固定資產稅** | 每年 | 評価額 × 1.4% |
| **都市計画稅** | 每年 | 評価額 × 0.3% |
| **所得稅（租金）** | 每年申報 | 租金收入扣除必要經費後的所得 |

### 外國人沒有日本居住地址的情況

**如果不住在日本：**
```
□ 不需要加入國民年金（日本年金）
□ 不需要加入國民健康保險
□ 但租金收入的所得稅仍然要申報
□ 建議透過稅理士處理年度申報
```

## 四、固定資產稅與都市計画稅

### 計算方式

```
固定資産税  = 、固定資産税評価額 × 1.4%
都市計画税 = 、固定資産税評価額 × 0.3%
──────────────────────────────────
合計税率   = 評価額 × 1.7%
```

### 住宅用地的減免優惠

**住宅用地（200㎡以下）有稅額優惠：**

```
評価額 ¥1,000萬元的土地為例（住宅用地）：

原本稅額：¥1,000萬 × 1.7% = ¥17萬/年
減免後（1/6）：約 ¥2.8萬/年

實際持有成本大幅降低！
```

### 減免的條件

```
□ 建物為住宅用途（民宿也算在內）
□ 土地面積在 200㎡以下
□ 建物建築面積的 10倍以內
```

## 五、租金收入的所得稅

### 計算方式

```
租金年收入（年租金總額）
  - 必要經費（折舊、修繕、管理費等）
= 課稅所得金額
  ↓
依照所得稅率計算
```

### 所得稅率（個人）

| 課稅所得金額 | 稅率 |
|-------------|------|
| ¥195萬以下 | 5% |
| ¥195萬～¥330萬 | 10% |
| ¥330萬～¥695萬 | 20% |
| ¥695萬～¥900萬 | 23% |
| ¥900萬～¥1,800萬 | 33% |
| ¥1,800萬～¥4,000萬 | 40% |

### 可計入必要經費的項目

| 項目 | 說明 |
|------|------|
| **折舊費** | 建物價值的折舊（住宅：RC 47年、木造 22年等）|
| **修繕費** | 維持建物狀態的維修費用 |
| **管理費** | 代管公司費用 |
| **保險費** | 火災保險、地震保險 |
| **借入利息** | 如果有房貸，利息可計入 |
| **租稅** | 固定資產稅等 |
| **消耗品** | 衛浴用品、清潔用品等 |
| **通信費** | Wi-Fi 費用等 |

## 六、ワンストップ制度（境外減免）

### 什麼是ワンストップ？

外國人在日本沒有固定住所的情況下，租金收入的所得稅可以透過「ワンストップ特例制度」處理。

**簡單說：**
- 不需要像日本人一樣進行複雜的稅務申報
- 租金所得由 Airbnb 或其他平台代扣所得稅
- 你收到的租金已經是扣除所得稅後的金額

**但建議：**
- 仍然要有日本的稅務顧問確認申報是否正確
- 如果有多個收入來源，可能需要自行申報

## 七、民泊新法的稅務要點

### 民宿收入的稅務特殊性

**民泊新法と申告：**
```
□ 民宿收入屬於「事業所得」或「雑所得」
□ 可以扣除必要經費
□ 赤字时可以和其他所得合算扣除
□ 外國人也有申告義務
```

### 建議的節稅方式

**1. 設備折舊**
```
家具・家電：5-6年折舊
裝修：殘存価値まで折舊
→ 每年可以扣除大額折舊費
```

**2. 火災保險計入**
```
保險費：全領可計入必要經費
→ 實際支出可以抵稅
```

**3. 租税公課**
```
固定資産税、都市計画税
→ 全領可以計入必要經費
```

## 八、交易安全相關法令

### 不動產交易的重要保護制度

**1. 重要事項說明（重要事項説明）**
```
不動產交易前，經紀有義務說明：
・土地的權利關係
・用途地域
・建築基準法的限制
・周邊環境（嫌悪施設等）
```

**2. 瑕疵擔保責任**
```
建物有瑕疵時，賣方有修復責任
・結構瑕疵：10年以内
・雨漏等：2年以内
```

**3. 住宅建物を建築交易的瑕疵（住宅品質確保法）**
```
新建住宅有10年的瑕疵擔保責任
中古住宅没有此保障
```

## 九、外國人特別注意事項

### 外國人常見的法律風險

**1. 土地所有權的特別規定**
```
□ 外國人可以取得土地所有權
□ 沒有任何法律限制
□ 但部分農業用地有特別規定
```

**2. 鄰地關係**
```
□ 日本的相鄰關係法規很嚴格
・建築物的高度限制
・日照權
・景觀條例
□ 建議事先了解
```

**3. 租賃契約終了時**
```
・借地借家法保護承租人
・即使出售，現有租客可能繼續有租賃權
・建議在購入前確認沒有既存租約
```

## 十、Recommended Professionals（推薦專業人士）

### 不動產交易需要聘請的專家

| 專家 | 役割 | 費用 |
|------|------|------|
| **土地上家屋所有人（代書）** | 過戶登記、登錄手續 | ¥10-30萬 |
| **宅地建物取引士** | 不動產交易的合法說明、交易確認 | 通常由經紀公司支付 |
| **稅理士（稅務士）** | 每年所得稅申報、節稅建議 | ¥3-8萬/年 |
| **不動產經紀（宅地建物取引業）** | 物件検索、交易媒介 | 賣方支付（通常是房價3%+6萬）|

### 如何找到信賴的專家？

**代書（土地上家屋所有人）：**
```
□ 搜尋「名古屋 土地家屋所有人 評判」
□ 請不動產經紀推薦
□ 在 Google 查看評價
□ 確認是否為「東京都不動產估價士資格試験合格者」
```

**稅理士：**
```
□ 搜尋「名古屋 確定申告 稅理士」
□ 確認是否為「東京都不動產估價士」
□ 建議找有處理外國人案例經驗的
```
