## Step 3：投報率計算

### 表面投報率

```
表面投報率 = 月租金 × 12 ÷ 取得価格
           = 7万 × 12 ÷ 1,080万
           = 84万 ÷ 1,080万
           = 7.78%（保守估算7萬/月）
（8萬/月：96万 ÷ 1,080万 = 8.89%）
```

### 實質投報率計算

**固定資産評価額估算**
```
評価額 = 土地評価額 + 建物評価額
土地評価額 ≈ 1,080万 × 65% = 702万
建物評価額 ≈ 殆零（木造39年 > 法定22年）

固定資産評価額 ≈ 702万
```

**年間持有コスト**
```
固定資産税：702万 × 1.4% = 9.83万/年
都市計画税：702万 × 0.3% = 2.11万/年
───────────────────────────
年間持有コスト合計：11.94万/年
```

**實質投報率**
```
実質投報率 = （年間租金 - 年間持有コスト）÷ 取得価格
           = （84万 - 11.94万）÷ 1,080万
           = 72.06万 ÷ 1,080万
           = 6.67%（保守估算7萬/月）

（8萬/月：84万 - 11.94万 = 72.06万 → 8万*12=96万，96-11.94=84.06万 → 7.78%）
```
