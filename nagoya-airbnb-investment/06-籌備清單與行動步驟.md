# ✅ 籌備清單與行動步驟

> 照表操課，從零到上架

---

## 階段一：準備期（Month 1-3）

### A. 財務準備

```
□ 評估可用資金（建議閒置資金的50%以內，不要影響生活）
□ 計算所有購屋成本（房價 + 7-10% 一次性費用）
□ 準備緊急預備金（房價的 10-15%）
□ 確認匯款額度（每人每年 NT$500萬外匯額度）
□ 決定是否用現金購入（多數台灣人選這個）
□ 設立日本旅遊計畫（至少一次實地看屋）
□ 試算未來持有成本（固定資產稅、代管費、保險）
□ 試算報酬率（年收入、淨收入、回收年限）
□ 心理準備：這筆錢投入後，至少 5-8 年不動用較安全
```

**量化目標參考（以¥1,500萬為例）：**
```
房價：¥1,500萬（ 約台幣330萬）
一次性成本：¥105萬（ 約台幣23萬）
裝修準備金：¥100萬（ 約台幣22萬）
預備金：¥50萬（ 約台幣11萬）
──────────────────────────
總需求：約台幣 386-400萬
```

---

### B. 帳戶與文件

```
□ 在台灣開外幣帳戶（台灣銀行、兆豐銀行）
□ 聯繫台灣銀行東京分行，詢問在台開戶可能性
□ 申請日本銀行帳戶（新生銀行、SBI NET銀行等）
□ 護照正本 + 影本（數份）
□ 護照公證（公證人公證，約 NT$800-1,200）
□ 資金來源證明（股票對帳單、存款證明等）
□ 社會安全碼（如有美國身份）或 ITIN（如需的美國稅號）
□ 聘請代書（很重要！）：聯繫當地不動產經紀推薦
□ 找稅理士（處理每年的所得稅申報）
□ 找代管公司（如果不住在日本）
```

**代書怎麼找：**
- 不動產經紀通常有配合的代書
- 搜尋「名古屋 土地家屋所有人」，找評價好的
- 事先要求報價，確認費用

**代管公司怎麼找：**
- Airbnb 官網有推薦清單（按「管理公司」搜尋）
- 搜尋「名古屋 民宿 管理会社」
- 當地不動產公司附設民宿管理部門

## 階段二：找房期（Month 3-6）

### C. 找房條件

```
□ 預算：¥800萬～2,500萬
□ 類型：一戶建（透天）3DK 以上
□ 地域：中村區 > 中區 > 熱田區
□ 用途地域：第二種住居地域 或 商業地域
□ 車站徒步時間：15分鐘以內（越近越好）
□ 屋齡：30年以內（較少維修問題）
□ 有停車位者佳
□ 不是不良水位區（淹水リスク）
□ 不是「再建築不可」的土地（很重要！）
□ 周邊沒有不良設施（附近沒有墓地、特種行業）
□ 沒有現有租賃契約（接手複雜）
```

### D. 區域調査（看屋前必做）

```
□ 用 Google Map 確認物件位置與周邊環境
□ 查詢用途地域（都市計畫圖，名古屋市政府官網）
□ 確認最近車站徒步時間（自己走一遍）
□ 查看周邊生活機能（超市、便利商店、餐廳）
□ 查詢區域犯罪率（Google 搜尋「治安 + 區域名稱」）
□ 查詢是否為淹水潛勢區域（NHKハザードマップ）
□ 查看最近的大眾交通樞紐和機場距離
□ 了解周邊 Airbnb 競爭情況（搜尋同一區域的 Airbnb 房源）
```

### E. 看屋重點

```
□ 建築結構（木造 vs 鐵骨 vs RC）
□ 屋齡與設備狀況（親眼確認）
□ 是否有壁癌、漏水、蟲害
□ 水電管線狀況（老舊管線可能要换）
□ 停車位（有沒有很重要）
□ 土地持分（獨立還是共有）
□ 是否為不良住宅（再建築不可 = 噩夢）
□ 確認沒有既存租賃契約
□ 測量實際空間（和廣告的面積可能有落差）
□ 觀察左隣右舎（是否為不良鄰居）
□ 確認土地權利（所有權還是他益權）
□ 確認是否有擔保或抵押
```

## 階段三：簽約與過戶（Month 6-8）

### F. 簽約前準備

```
□ 聘請代書（讓代書審查契約）
□ 申請民宿許可需要的文件（提前準備）
□ 申請房貸（如果需要的話）
□ 確認尾款匯款時間
□ 準備好護照公證文件
□ 確認手付金金額與支付方式（通常10%）
□ 確認合約內容（請代書詳細解說）
□ 確認是否為「瑕疵物件」（重要！）
□ 確認「解除權」條款
□ 準備好突發支出的資金
□ 拍物件各角度的照片（記錄現狀）
□ 申請建築物履歷調查（登錄情報證）
□ 確認溫泉Gas等公用事業帳戶
□ 確認管理費/修繕金的支付方式
□ 確認不動產取得稅、登錄許可稅的支付方式
□ 申請民宿許可（可以同步進行，不一定要拿到房子才能申請）
```

### G. 過戶流程

```
Week 1：簽約 + 支付手付金（10%）
        ↓
Week 2-4：银行贷款審查（如果需要）
        ↓
Week 4-6：尾款支付 + 過戶登記
        ↓
Week 6-8：取得「権利証」（權利書）
        ↓
Week 8-10：民宿許可申請（向名古屋市政府）
        ↓
Week 10-12：Airbnb 上架 ✅
```

## 階段四：裝修與準備（Month 8-9）

### H. 裝修重點

```
□ 民宿許可的設施標準確認
□ 滅火器設置（有効期限確認）
□ 緊急照明設置
□ 每間房的對外窗確認
□ 識別標示（民宿標示牌）安裝
□ 獨立出入口的確認
□ 智能門鎖安装（密碼鎖，方便外國旅客）
□ Wi-Fi 申請與測試
□ 家具採購（床、沙發、衣櫃）
□ 家電採購（冰箱、洗衣機、空調、熱水器）
□ 衛浴用品（毛巾、浴巾、洗髮精、沐浴乳）
□ 廚房用品（鍋碗瓢盆、熱水壺）
□ 消耗品（垃圾袋、衛生紙、清潔用品）
□ 嬰兒用品（嬰兒床、高腳椅）— 加分項
□ 多語言說明書（Wi-Fi、門鎖、垃圾分類）
□ 迎賓禮物（當地零食）
□ 清潔工具（吸塵器、拖把、清潔劑）
□ 聘請專業清潔公司（上架前大掃除）
□ 電力容量確認（老房子可能不夠）
□ 瓦斯確認（都市瓦斯 or プロパン瓦斯）
□ 化糞池清理（老房子特別重要）
□ 拍攝房源照片（光線好的時候，至少10張）
```

## 階段五：法律與許可

### I. 民宿許可申請

```
□ 確認物件所在用途地域
□ 向名古屋市政府觀光部門提交申請
□ 文件準備：
  □ 民宿申請表（公式様式）
  □ 建築物符合標準的確認書
  □ 消防檢查合格證（事前，需先通過）
  □ 申請人身分證明（護照）
  □ 土地及建物謄本
  □ 事業計畫書（簡單的收支預估）
□ 加入住宅民宿責任保險
□ 申請「免責事項」確認
□ 確認垃圾處理計劃（名古屋市的規定）
□ 製作住房者名冊（公安委員會要求）
□ 申請稅籍（固定資產稅申告）
□ 確認是否需要申請「観光旅行者住宿税」（目前名古屋無）
□ 領取「民宿登錄完了通知書」
□ 在 Airbnb 填入民宿登錄番号
□ 確認許可有效期限（通常3年，需更新）
□ 設置識別標示（玄関外）
□ 加入 AARP 或類似的安全確認系統
□ 確認 ABNB 平台的「法律合規」設定
□ 設置噪音偵測器（建議，預防投訴）
□ 確認鄰居沟通记录（如果有）
□ 申請Wi-Fi的民宿用方案（可能比較便宜）
□ 確認電費契約（住宅用 or ビジネス用）
```

## 最終：持續營運

### K. 每年都需要做的

```
□ 所得稅申報（每年2-3月）
□ 固定資產稅繳納（每年）
□ 民宿許可更新（每3年一次）
□ 火災保險更新
□ 設備檢查（每年）
□ 牙口清掃（每年的化糞池清理）
□ 稅理士費用
□ 代管公司費用（按月計算）
□ 稅金檢視（有可能合法節稅）
□ 市場行情評估（房價/租金有没有變化）
□ 競爭對手分析（周邊新上架的 Airbnb）
□ 評價管理（維持 4.8+ 星的評價）
□ 申請提高住房率的行銷優惠（Airbnb 提供）
□ 考慮淡旺季的定價調整
□ 緊急應變計劃更新（電話號碼更換等）
□ 稅務師年度會議（檢討去年、規劃今年）
□ 考慮是否擴展（再買一間？）
□ 或考虑是否退出（報酬率低於預期）
```

## ⚡ 快速總結：最重要的三件事

**1. 找代書**
外國人買房，沒有代書寸步難行。

**2. 算清楚成本**
表面利潤和實際利潤差很多，要把所有費用都算進去。

**3. 180天的淡旺季**
名古屋冬季淡季住房率很低，不要只看旺季數字。
