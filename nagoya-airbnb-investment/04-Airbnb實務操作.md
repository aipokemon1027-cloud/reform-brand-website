# 🏡 Airbnb 實務操作

---

## 一、什麼類型的房子適合做 Airbnb？

### 一戶建（透天）的優勢

```
✅ 隱私性高（旅客體驗好）
✅ 空間大，可容納多人
✅ 獨立出入口，不會打擾鄰居
✅ 沒有管委會禁止民宿的問題
✅ 符合「深度在地旅行」的趨勢
```

### 不適合的類型

```
❌ 公寓大樓（管委會可能禁止）
❌ 狹小空間（1R/1K，容納人數受限）
❌ 屋齡過老（40年以上，維修成本高）
❌ 周邊環境差（聲音、安全問題）
```

## 二、Airbnb 定價策略

### 名古屋市場行情（日租參考）

| 區域 | 1-2人住 | 3-4人住 | 5-6人住 |
|------|---------|---------|---------|
| 中村區 | ¥5,000-7,000 | ¥7,000-10,000 | ¥10,000-14,000 |
| 中區 | ¥6,000-8,000 | ¥8,000-12,000 | ¥12,000-16,000 |
| 熱田區 | ¥4,000-6,000 | ¥6,000-9,000 | ¥8,000-12,000 |

### 淡旺季定價

```
旺季（賞櫻4月、黃金週5月、秋季11月）：
→ 定價 +30-50%（最高日租的1.5倍）

普通日：
→ 正常定價

淡季（1-3月）：
→ 定價 -20%（維持競爭力的最低水位）
→ 低於這個價錢，不如做月租
```

### 定價工具

**Airbnb 內建 Smart Pricing（智慧定價）：**
- 會根據市場供需自動調整價格
- 建議打開，但設定上下限（不要讓它變成 ¥1 的價格）

## 三、提高住房率的技巧

### 提升房源吸引力的方法

**1. 照片是關鍵**
```
✅ 白天自然光拍攝
✅ 廣角鏡頭（讓空間看起來更大）
✅ 整潔、簡單的室內布置
✅ 突出一戶建的特色（庭院、陽台）
✅ 拍攝周邊景點（熱田神宮就在旁邊）
```

**2. 房源描述要寫什麼**
```
必備內容：
□ 準確的面積和房間數（3DK 等）
□ 最近的車站 + 徒步時間
□ Wi-Fi 密碼（旅客最在意）
□ 附近超市/便利商店
□ 入住方式（密碼鎖/親自交付）
□ 垃圾處理方式（日本特殊要求）

加分內容：
□ 建築歷史或特色
□ 當地人推薦的私房景點
□ 如何使用大眾交通
```

**3. 設備清單（標配 vs 加分）**

| 標配（沒有會被抱怨）| 加分（提升評價）|
|---------------------|-----------------|
| Wi-Fi | 洗衣機（長期住宿需要）|
| 獨立衛浴 | 停車位 |
| 冷氣 / 暖氣 | 廚房完整設備 |
| 吹風機 | 嬰兒用品（嬰兒床、高腳椅）|
| 毛巾 / 浴巾 | 翻譯說明（英文/中文）|
| 基本的洗髮精/沐浴乳 | 當地零食/飲品迎賓 |

## 四、管理模式選擇

### 如果你住在日本

**自助管理：**
- 親自打掃、迎接客人
- 最省錢，但最花時間
- 適合時間充裕的人

### 如果你不住在日本（推薦）

**委託代管公司：**

| 服務內容 | 費用 |
|----------|------|
| 基本管理 | 月租金的 10-15% |
| 全方位管理（含打掃）| 月租金的 20-30% |
| 高級管理（含行銷）| 月租金的 30%+ |

**全方位管理通常包含：**
- ✅ 入住 / 退房対応
- ✅ 房間清潔（每次 ¥3,000-8,000）
- ✅ 設備故障対応
- ✅ 客人問題対応
- ✅ Airbnb 訊息回覆
- ❌ 不包含：維修費用

**如何找代管公司：**
- Airbnb 官網推薦清單
- 搜尋「名古屋 民宿 管理会社」
- 當地不動產經紀推薦

## 五、Airbnb 帳號設定

### 上架前必須準備的

```
□ 民宿許可編號（向名古屋市政府申請）
□ 許可證明文件（上傳到 Airbnb）
□ 清晰的房源照片（至少5張）
□ 房源描述（英文/日文）
□ 設定價格與清潔費
□ 設定最少/最多住宿天數
□ 設定入住時間
□ 加入住房保障計劃（Airbnb 提供）
```

### 許可編號顯示位置

```
Airbnb 房源頁面
↓
「uhn 識別碼」或「 license number」
↓
填入民宿登錄番号
↓
系統會自動驗證 ✅
```

## 六、接待外國旅客的眉角

### 語言問題

**英文說明是標配：**
```
□ Wi-Fi 密碼（英文）
□ 如何使用門鎖
□ 垃圾分類說明（日本垃圾分類複雜）
□ 附近地圖/交通指引
□ 緊急聯絡方式
□ 退房注意事項
```

**建議用多語言版本（英文 + 繁體中文）**

### 日本特殊文化

```
□ 拖鞋文化：室內換拖鞋
□ 安靜時間：晚上 10 點後不要大聲
□ 垃圾分類：日本垃圾分 4-5 類，要先教客人
□ 溫泉/浴缸：如果是溫泉住宅要先說明
□ 菸味：日本室內全面禁菸
```

## 七、提高評價的方法

Airbnb 評價直接影響住房率：

### 快速提升評價的方法

```
1. 迎賓禮物：當地零食 or 免費 Wi-Fi 蛋（租借）
2. 快速回覆：30分鐘內回覆，Airbnb 會加分
3. 零距離入住：智慧門鎖密碼，旅客便利
4. 如實描述：不要過度修圖，圖文不符會被抱怨
5. 小驚喜：季節性裝飾（聖誕節、萬聖節）
6. 緊急対応：問題發生時立刻處理
```

### 常見的低分原因

```
❌ 照片與實際不符
❌ Wi-Fi 速度太慢
❌ 吵雜、隔壁太吵
❌ 設備故障（浴室、空调）
❌ 蟲害（床蟲、螞蟻）
❌ 交通不便但沒先說
```

## 八、淡旺季管理策略

### 名古屋淡旺季分布

```
淡季：1月、2月、3月（冬季 + 賞花前）
普通：6月、7月、8月（梅雨、夏季）
旺季：4月、5月、10月、11月（櫻花、黃金週、秋季）
```

### 淡季策略

**1. 降低價格**
```
標準日租：¥8,000 → ¥5,500（-30%）
目標住房率：從 70% 提升到 80%+
```

**2. 鎖定商務客（週間需求）**
```
日～四：商務旅客（低價競爭）
五～六：觀光旅客（正常價）
```

**3. 月租方案**
```
淡季與其空著，不如做月租
月租行情：¥15-20萬/月
→ 比 Airbnb 日租收入更穩定
```

**4. 轉做長租墊檔**
```
如果 Airbnb 住房率太低
→ 改為半年/一年長租
→ 雖然收入降低，但起碼有穩定現金流
```

## 九、緊急情況対応

### 常見問題的處理方式

| 問題 | 立即處理 |
|------|----------|
| 設備故障（水管、空調）| 聯繫代管公司或 plumber |
| 門鎖問題 | 遠端重設密碼 or 派人處理 |
| 客人受傷 | 叫救護車 + 聯繫代管 |
| 鄰居投訴 | 立刻聯繫客人了解情況 + 道歉 |
| 警察來敲門 | 可能是民宿申報問題，請代書対応 |

### 建議的緊急聯絡清單

```
□ 代管公司電話：
□ 當地 plumber（水電）：
□ 當地locksmith（開鎖）：
□ 當地清潔公司：
□ 名古屋市政府觀光部門：
□ 當地警察局：
□ 急救/救護車：119
```

## 十、法律合規的最後提醒

```
□ 民宿許可編號是否有效（每年更新）?
□ 是否超營業天數限制（滾動3個月180天）?
□ 住房者名冊是否隨時備查?
□ 消防設備是否在有效期內?
□ 垃圾處理是否按照規定?
□ 是否有噪音投訴紀錄?
```
