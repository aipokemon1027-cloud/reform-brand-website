## 一、申請資格的基本前提

### 可以申請民宿的基本條件

```
□ 建物為合法建築（確認済み）
□ 用途地域為可經營民宿的區域
□ 樓層以下消防設備符合標準
□ 結構安全確認
□ 排水・衛生設備正常
```

### 外國人可以申請嗎？

**可以。** 但需要：
- 本人或代理人（代書）提出申請
- 護照影本 + 公證
- 日本銀行帳戶（收取租金用）
- 無需在留資格

## 二、申請流程 Step by Step

```
Step 1：確認用途地域（事前調査）
        ↓
Step 2：設置消防設備（消防法適合）
        ↓
Step 3：製作申請文件
        ↓
Step 4：向名古屋市政府提交申請
        ↓
Step 5：市政府審查（約2-4週）
        ↓
Step 6：領取民宿登錄完了通知書
        ↓
Step 7：在 Airbnb 填入登錄番号
```

## 三、申請所需文件（必要書類）

### 基礎文件

| 文件 | 說明 |
|------|------|
| 民宿許可申請表（民宿事業許可申请书） | 官公署格式，包含申請人基本資料 |
| 住民票または在留カード | 申請人身分證明 |
| 护照影本 | 需要公證 |
| 土地及建物謄本（登錄情報證） | 確認所有權 |
| 事業計畫書 | 簡單的收支預估 |

### 設施相關文件

| 文件 | 說明 |
|------|------|
| 消防設備設置証明書 | 向當地消防署申請檢查後核發 |
| 建築物符合標準確認書 | 結構安全、排水、採光等符合基準 |
| 位置図・見取り図 | 建物平面圖 |
| 設備一覧 | 冷氣、衛浴、Wi-Fi 等設備清單 |

### 管理體制文件

| 文件 | 說明 |
|------|------|
| 管理者選任報告書 | 民宿管理者姓名、聯絡方式 |
| 緊急時対応計画 | 緊急情况處置流程 |
| 苦情対応計画 | 處理鄰居投訴的機制 |
| 滞在者名簿管理方法 | 住房者名冊管理方式 |
| ゴミ処理計画 | 垃圾分類處理方式 |

## 四、消防檢查（消防法適合性検査）

### 為什麼要先做消防檢查？

**沒有通過消防檢查，申請民宿許可不會通過。**

### 消防檢查的項目

```
□ 設置場所的安全確認
□ 逃生通道暢通（2方向以上）
□ 設置滅火器（有效期限內）
□ 設置住宅用火災警報器
□ 設置緊急照明装置
□ 確認插座和電線的安全
□ 瓦斯設備的安全確認
```

### 申請消防檢查的流程

```
Step 1：向名古屋市政府消防局（或當所轄消防署）提出申請
        ↓
Step 2：消防署人員到場檢查
        ↓
Step 3：不合格項目改善
        ↓
Step 4：領取「消防法令適合証明書」
```

### 消防檢查費用

| 項目 | 費用 |
|------|------|
| 申請費用 | 約 ¥3,000～8,000 |
| 設備設置費 | 約 ¥50,000～200,000（視現有設備）|
| 改善工程（必要時）| 未知，視情況 |

## 五、申請費用與時間

### 申請費用一覽

| 項目 | 費用 |
|------|------|
| 民宿許可申請費用 | 約 ¥15,000（登錄費用）|
| 消防檢查費用 | 約 ¥3,000～8,000 |
| 代書代辦費 | 約 ¥50,000～150,000 |
| 律師/稅理士費用（如需要）| 約 ¥30,000～100,000 |
| **合計** | **約 ¥118,000～273,000** |

### 審查時間

```
正常審查：約 2-4 週
有補正要求：再追加 2-4 週
旺季（春季/黃金週前）：可能更久
```

### 許可有效期限

**民宿登錄番号有效期限：3年**

期滿前需要更新，否則無效。

## 六、申請時的常見被駁回原因

### 補正要求（卻下理由）排行榜

**1. 消防設備不符合標準**
```
・滅火器過期
・沒有設置緊急照明
・逃生通道被堵塞
・沒有住宅用火災警報器
```

**2. 用途地域不符**
```
・在不准許民宿經營的區域
・建議申請前先確認「民泊區域計画」
```

**3. 建築物結構問題**
```
・天花板高度不足
・採光不足（每間房需要有對外窗）
・排水設備不良
```

**4. 管理體制不完善**
```
・沒有提供緊急対応計画
・管理者聯絡方式不完整
・名冊管理方式說明不清
```

**5. 垃圾處理計画不充分**
```
・沒有說明如何處理不同類型的垃圾
・沒有說明垃圾回收日
```

## 七、申請後的義務

### 取得許可後必須遵守的事項

```
□ 在房源頁面顯示民宿登錄番号（Airbnb 等平台）
□ 製作住房者名冊並保存（公安委員會要求，3年間）
□ 每年更新民宿許可（提前3個月申請）
□ 如實申報租金收入（所得稅）
□ 繳納固定資產稅、都市計画稅
□ 接受不定期檢查
□ 投保住宅民宿責任保險
□ 噪音管理：晚上10點後注意
□ 垃圾分類處理
```

### 住房者名冊要記錄什麼？

| 記錄項目 | 說明 |
|----------|------|
| 姓名 | 住宿者全名 |
| 住所 | 國籍 + 居住地址 |
| チェックイン日 | 入住日期 |
| チェックアウト日 | 退房日期 |
| 客室番号 | 房間號碼 |

> ⚠️ 這些資料要保存 3 年，隨時接受公安委員會調閱。

## 八、不同類型申請的差異

### 住宅型民宿 vs 旅館業許可

| 項目 | 住宅型民宿（民泊新法）| 旅館業許可 |
|------|---------------------|-----------|
| 申請單位 | 地方政府 | 保健所 |
| 天數限制 | 180天（住宅區）| 無限制 |
| 申請費用 | 較低 | 較高 |
| 設施標準 | 較寬鬆 | 嚴格 |
| 適用對象 | 一戶建、公寓 | 飯店、商業設施 |
| 一戶建適用 | ✅ 適用 | ⚠️ 很難達標 |

## 九、申請費用減免的可能性

### 合法節省費用的方式

**1. 自己準備文件（DIY）**
```
・申請表：自己填寫（免費）
・位置図・見取り図：用APP或免費軟體製作
→ 省下代書費 ¥50,000-150,000
```

**2. 參加政府說明會**
```
・部分地方政府有免費說明會
・有機會直接詢問審查人員
→ 省下諮詢費 ¥10,000-30,000
```

**3. 使用標準格式**
```
・國土交通省的標準文件範本
・直接下載使用，不需要客製化
→ 省下文件製作費 ¥10,000-20,000
```
