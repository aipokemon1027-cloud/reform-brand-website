- 狀態：已安裝但無法使用

- GitHub：Danie1/threads-api（2023年已存檔，不再維護）
- 結論：❌ 不建議使用，太舊了

**2. threadspipepy（官方 Meta Threads API 包裝）**
- 狀態：已安裝成功
- 優點：使用官方 Meta API，穩定且長期支援
- 缺點：需要完整 OAuth 設定（App ID, App Secret, Access Token, User ID）
- 需要：
  1. Facebook Developer 帳號
  2. 建立 App（Business type）
  3. 啟用 Threads API
  4. OAuth 流程（需要 redirect URI）
  5. 拿到長效 Access Token
- 結論：✅ 長期方案，但需要 15-30 分鐘設定
