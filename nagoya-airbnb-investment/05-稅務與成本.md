# 💰 稅務與成本

---

## 一、持有成本：每年固定支出

### 固定資產稅 + 都市計画稅

這是日本不動產每年最大的固定支出。

```
固定資產稅 = 、固定資産税評価額 × 1.4%
都市計画稅 = 評価額 × 0.3%
─────────────────────────
合計 = 評価額 × 1.7%（標準税率）
```

**一戶建的評價額通常低於市場價格：**
```
市場價格：¥1,500萬
評價額：約 ¥800萬～1,000萬（視情況）

年稅額：
¥1,000萬 × 1.7% = ¥17萬/年
```

> 住宅用地（200㎡以下）有稅額減免優惠，實際可能更低（¥10-15萬左右）。

## 二、租金收入的所得稅

### 日本所得稅率（個人）

| 租金年收入 | 稅率 |
|-----------|------|
| ¥195萬以下 | 5% |
| ¥195萬～¥330萬 | 10% |
| ¥330萬～¥695萬 | 20% |
| ¥695萬～¥900萬 | 23% |
| ¥900萬～¥1,800萬 | 33% |

**計算方式：**
```
租金年收入 ¥144萬（之前試算的數字）
- 必要經費（折舊、修繕等）
= 課稅所得（約 ¥100-110萬）

第一段：¥195萬 × 5% = ¥9.75萬（但收入低於這個）
→ 實際繳納可能只有 ¥5-7萬左右
```

> ⚠️ 日本所得稅有「租屋損耗」扣除，可申請。建議請代書或稅理士幫你計算。

## 三、外國人要申報日本所得稅嗎？

**要的。** 外國人在日本有收入，就必須申報。

### 申報方式

```
□ 每年2月16日～3月15日：自行申報所得稅（個人確定申報）
□ 建議聘請稅理士（稅務代辦）處理，費用約 ¥3-8萬/年
□ 台灣人可申請「日中租稅協定」避免雙重課稅
```

---

## 四、所得稅之外的地方税

```
□ 個人事業稅：約 ¥2-5萬/年（視收入）
□ 市民稅・縣民稅：所得稅的約10%
```

---

## 五、ワンストップ導入（境外租金）

如果你是住在台灣的外國人（無日本居住地址）：

```
□ 不需要加入日本的年金保險
□ 不需要扣繳（日本稅法稱「公的年金」）
□ 但租金收入仍需申報所得稅
□ 建議找日本的稅理士每年處理
```

## 七、完整的年度報酬試算

### 購入條件

```
購入價格：¥1,500萬（中村區一戶建）
首付（假設全額現金）：¥1,500萬
```

### 收入

```
年住房天數：180天
平均日租：¥8,000
─────────────────
年收入：¥144萬
```

### 支出

| 項目 | 金額 |
|------|------|
| 固定資產稅等 | -¥15萬 |
| 民宿保險 | -¥3萬 |
| 代管費（20%）| -¥29萬 |
| 裝修預備金 | -¥10萬 |
| 稅金（所得稅等）| -¥10萬 |
| 其他 | -¥5萬 |
| **合計** | **-¥72萬** |

```
年收入：¥144萬
年支出：¥72萬
─────────────
淨收入：¥72萬/年
淨報酬率：4.8%
```

> **合理的報酬率預期：4-6%。** 別期待太高，但也別太悲觀。

## 八、ワンストップ制度（免稅退稅）

如果你沒有日本居住地址，可以利用「ワンストップ特例制度」：

**簡單說：**
- 租金收入的所得稅可以由 AirTax 等代扣
- 不需要自行申請
- 但建議還是要有日本稅務顧問確認

## 九、台灣人要注意的：海外所得

### 台灣的稅務

```
在台灣的收入：
□ 海外所得（非台灣來源）目前免稅
□ 但如果日本租金收入匯回台灣，建議如實申報
□ 台灣個人有最低稅負制（但門檻很高）
```

**建議：**
- 日本的租金收入已經在日本繳過所得稅
- 台灣目前對海外所得課稅門檻很高（基本不用擔心）
- 如果有疑問，問台灣的會計師

## 十一、削減成本的方法

### 合法節稅

**1. 裝修費用計入必要經費**
```
更換家具、家電：可計入必要經費
家具折舊：通常 5-6 年攤提
```

**2. 借貸利息**
```
如果用房貸買房，利息可以計入必要經費
但多數台灣人用現金，沒有這個選項
```

**3. 火災保險費**
```
火災保險費：可計入必要經費
```

**4. 民宿関連費用**
```
民宿許可相關費用、行政手續費、管理費
全部可計入必要經費
```

## 十二、結論：划不划算？

**以 ¥1,500 萬中村區一戶建為例：**

| 項目 | 數字 |
|------|------|
| 年收入 | ¥144萬 |
| 年支出 | ¥72萬 |
| 淨收入 | ¥72萬 |
| 淨報酬率 | **4.8%** |

**這個報酬率怎麼看？**
- 比存銀行（0.5-1%）好很多
- 比台北房東（2-3%）好
- 但要付出時間心力管理
- 日幣貶值風險要承擔

**適合的人：**
- 有閒置資金、不著急用錢
- 對日本有興趣、願意學習
- 能承受一些管理麻煩
- 認同「不動產作為資產配置」的想法

**不適合的人：**
- 期待快速致富
- 不願意付出時間管理
- 資金需要高度流動性
- 無法承受日幣波動
