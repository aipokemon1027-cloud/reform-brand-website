## Step 3：投報率計算

### 表面投報率

```
表面投報率 = 月租金 × 12 ÷ 取得価格
           = 3万 × 12 ÷ 380万
           = 36万 ÷ 380万
           = 9.47%（估）
```

### 実質投報率計算

**固定資産評価額估算**
```
評価額 = 土地評価額 + 建物評価額
土地評価額 ≈ 380万 × 70% = 266万
建物評価額 ≈ 殆零（木造54年 >> 法定22年）

固定資産評価額 ≈ 266万
```

**年間持有コスト**
```
固定資産税：266万 × 1.4% = 3.7万/年
都市計画税：266万 × 0.3% = 0.8万/年
───────────────────────────
年間持有コスト合計：4.5万/年
```

**実質投報率**
```
実質投報率 = （年間租金 - 年間持有コスト）÷ 取得価格
           = （36万 - 4.5万）÷ 380万
           = 31.5万 ÷ 380万
           = 8.29%（保守估算3万/月）
           
（樂觀估算3.5万/月：39万 - 4.5万 = 34.5万 → 9.08%）
```

## 💡 總結建議

### ✅ 優點
- **極低價**：380萬，入手門檻低
- **實質投報率8.29%**：可接受（但需大口折扣後）
- **二方道路+角地**：接道良好，地理條件不差
- **土地所有權**：永久持有
- **即時引渡**：馬上可以開始處理

### 🔴 重大缺點（紅旗）
- **違法建築**：建蔽率超标（40%規定 vs 實際81.8%）— 最高級風險
- **増築未登記**：1F部分未合法登記，無法申請房貸
- **雨漏**：1F洋室，結構安全存疑
- **無給湯器/電表**：設備不全，無法立即入住
- **汲取化糞池**：維護成本+改接下水道未知數
- **木造54年**：已超耐用年数，銀行不可能給房貸

### ⚠️ 結論

**⚠️380萬的原價風險過高，需大議價或卖方承擔維修**

**建議：**
- 要求降價至 **150-200萬**（合理土地價值）
- 或要求**卖方負擔全部維修費用**
- 最安全的做法：**拆除新建**，評估是否可建2層住宅

**❌ 不建議直接出租（需先解決雨漏+違法問題）**
**⚠️ 若能以150-200萬購入，投資價值浮現（実質投報率可達15%+）**
