# 🗺️ 名古屋投資區域分析

---

## 名古屋 Basics（為什麼選名古屋）

- 日本**第三大都市**（僅次東京大阪）
- 人口：約 230 萬
- 交通樞紐：JR新幹線、磁浮、**中部國際機場**
- 產業：Toyota、汽車、航空宇宙、機器人
- 外國遊客：2024年約 5,000 萬 overnight stays

**為什麼選名古屋：**
1. 房價比東京大阪便宜 30-50%
2. 民宿法規比東京大阪友善
3. 機場在，名鐵直達市區，外國旅客多
4. 商務旅客剛性需求（週間住房率穩定）

---

## 🥇 第一名：中村區（なごやまちら）

**名古屋車站所在地**，整個都市的心臟。

### 推薦原因：
- 🚉 **交通最強**：JR、地鐵、名鐵、近鐵全部交會
- 🧳 **旅客流量最大**：每天轉乘人數 100 萬+
- 💼 **商務客多**：週間住房率穩定
- 💰 **價格適中**：一戶建 ¥1,000萬～2,500萬

### 周邊景點：
- 名古屋城（地鐵15分）
- 榮商圈（地鐵10分）
- 磁浮鐵道博物館（JR30分）

### 指標數據：

| 項目 | 數值 |
|------|------|
| 一戶建價格 | ¥1,000萬～2,500萬 |
| 月租金行情 | ¥6萬～12萬 |
| 日租行情 | ¥7,000～10,000 |
| 車站徒步範圍 | 10分鐘以內優先 |

---

## 🥈 第二名：中區（なかく）

**名古屋市政府所在**，市中心精華區。

### 推薦原因：
- 🏯 **觀光核心**：名古屋城、榮商圈、大須觀音
- 🛍️ **商業發達**：餐廳、商場林立
- 🚇 **地鐵覆蓋密集**：交通方便
- 🏢 **商業地域比例高**：可能可以突破180天限制

### 指標數據：

| 項目 | 數值 |
|------|------|
| 一戶建價格 | ¥1,200萬～3,000萬 |
| 月租金行情 | ¥8萬～15萬 |
| 日租行情 | ¥8,000～12,000 |
| 特色 | 觀光+商務雙重需求 |

---

## 🥉 第三名：熱田區（あつたくない）

**熱田神宮所在地**， CP值最高的選擇。

### 推薦原因：
- ⛩️ **熱田神宮**：日本最重要的神社之一，觀光客穩定
- 💰 **價格最低**：門檻最友善
- 🏠 **住宅氛圍濃**：適合家庭旅客
- 📉 **入手風險低**：價格低，，就算結果不如預期也不會大虧

### 指標數據：

| 項目 | 數值 |
|------|------|
| 一戶建價格 | ¥800萬～1,800萬 |
| 月租金行情 | ¥5萬～9萬 |
| 日租行情 | ¥5,000～8,000 |
| 適合 | 預算有限、第一次投資 |

## 實際案例：中村區一戶建報酬試算

### 購入條件

```
購入價格：¥1,500萬（中村區、徒步10分）
類型：一戶建 3DK（約30坪）
用途地域：第二種住宅地域
```

### 收入試算

```
目標住房率：70%（扣除空窗期，合理預期）
年住房天數：365 × 70% = 255天
但上限180天 → 用180天計算

日租設定：¥8,000（中等價位）
年總收入：180天 × ¥8,000 = ¥144萬
```

### 支出試算

| 項目 | 年支出 |
|------|--------|
| 固定資產稅 | ¥10萬 |
| 都市計画稅 | ¥3萬 |
| 民宿保險 | ¥3萬 |
| **代管費（20%）** | **¥29萬** |
| 裝修攤提 | ¥10萬 |
| 其他支出 | ¥7萬 |
| **合計** | **¥62萬** |

### 最終數字

```
年收入：¥144萬
年支出：¥62萬
─────────────
淨收入：¥82萬/年
淨報酬率：¥82萬 ÷ ¥1,500萬 = 5.5%
```

> **合理的報酬率預期：4-6%。** 不要期待 10% 以上的報酬，那不正常。

## 結論

**首選：中村區（名古屋駅周邊）**
- 交通方便 = 空室率低
- 商務 + 觀光雙重需求
- 入手門檻適中

**CP值：熱田區（熱田神宮周邊）**
- 價格低，風險小
- 觀光客穩定
- 適合預算有限的首購族
